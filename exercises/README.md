# Exercises

Work in these directories. Each one starts where the previous exercise ended, so you can jump in
anywhere.

| Directory | Exercise | You start with | You end with |
| --- | --- | --- | --- |
| `01-ros-workspace/` | [1](https://prefix-dev.github.io/roscon-2026-declarative-ros-workspaces-with-pixi/exercises/01-ros-workspace/) | An empty directory | A ROS 2 workspace running turtlesim |
| `02-ros-package/` | [2](https://prefix-dev.github.io/roscon-2026-declarative-ros-workspaces-with-pixi/exercises/02-ros-package/) | A workspace and an unwired ROS package | Pixi building your package, with CUDA declared |
| `03-collaboration/` | [3](https://prefix-dev.github.io/roscon-2026-declarative-ros-workspaces-with-pixi/exercises/03-collaboration/) | A single-platform workspace | Every platform, CI and a published package |

The finished versions live in [`../solutions/`](../solutions/). They are installed and smoke-tested
on Linux, macOS and Windows on every commit, so if something here does not work, compare against
those.

Instructions are on the [workshop site](https://prefix-dev.github.io/roscon-2026-declarative-ros-workspaces-with-pixi/exercises/).
